# 🔥 Forest Fire Prediction & Simulation System

## 📌 Project Description
This project predicts forest fire risk using Machine Learning and simulates fire spread using Cellular Automata.

It uses environmental parameters like:
- Temperature
- Humidity
- Wind Speed
- NDVI (Normalized Difference Vegetation Index)
- NBR (Normalized Burn Ratio)

---

## 🎯 Objectives
- Detect fire-prone areas
- Predict fire risk using ML
- Simulate fire spread
- Provide visualization for analysis

---

## 🧠 Technologies Used
- Python
- Scikit-learn (Random Forest)
- NumPy
- Pandas
- Matplotlib
